# 10-Model Identity-Consistency Bake-off — Natalie Ruiz / Real Trust Law

Every concept was generated on a **different image model** (same two reference photos of Natalie as identity input) so the client can compare which model holds her likeness — and which can also set clean ad typography in one shot.

Scoring: **Likeness** (does she look like the same real person as the reference photos), **Typography** (did the exact ad copy render correctly), **Scene** (editorial quality / brief adherence). 1–5, judged visually on the final saved files.

## Working recommendation (updated as results land)
- **Identity + typography in one shot:** Google Nano Banana Pro is the safest single model for finished ad creative.
- **Best pure scene/typography:** Seedream 5.0 Pro — pair it with a face-swap/likeness pass, or use it for wide shots where Natalie is small in frame.
- Models that garble text (Ideogram character mode, FLUX Kontext on long copy) are still usable if copy is set in Figma/Photoshop over a clean generated plate.
