# Direct Builders — B2B Launch Campaign (Batch 1)

Six Instagram/LinkedIn-ready posts (1080×1350 → exported at 2160×2700) executing the B2B strategy's message pillars. Built from the brand system in `../BRAND-CREATIVE-DIRECTION.md`: dark charcoal + copper accent (mood-board direction), Space Grotesk / Plus Jakarta Sans / JetBrains Mono, real project photography, the actual logo, and the owner cutout.

## Files

- `templates/` — HTML sources (`brand.css` is the shared design system)
- `assets/` — logo, owner photo + cutout, project photography (from directbuilders.net), self-hosted brand fonts, one AI-generated aerial (`condo-aerial.jpg`, FLUX.2 Klein via fal)
- `output/` — final PNGs, ready to post
- `render.js` — re-renders all templates (`npm i playwright-core && node render.js`)
